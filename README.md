# 🎓 Student Management System

A simple and responsive Student Management System developed using HTML, CSS, and JavaScript.

The project allows users to add, search, view, and delete student records. It also calculates student grades and displays basic statistics.

## 🚀 Features

- Add new student records
- Store student name, roll number, course, and marks
- Automatically calculate grades
- Display Pass/Fail status
- Search students by name, roll number, or course
- Delete student records
- Display total number of students
- Calculate average marks
- Display number of passed students
- Store data using browser Local Storage
- Responsive design for mobile and desktop

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Add student details using the form.
5. Use the search box to find students.

## 📊 Grading System

| Marks | Grade |
|------:|:------|
| 90-100 | A+ |
| 80-89 | A |
| 70-79 | B |
| 60-69 | C |
| 50-59 | D |
| Below 50 | F |

A student is considered passed when the marks are 40 or above.

## 💾 Data Storage

Student information is stored in the browser using Local Storage. Therefore, the data remains available even after refreshing the page on the same browser.
